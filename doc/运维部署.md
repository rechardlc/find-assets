# 数字货币扫描器运维部署

本文档描述 **crypto-scanner** 在 Google Cloud（GCP）上的部署与日常运维方式，采用已验证可行的路径：

- **本机**：交叉编译 Linux 二进制，提交到 Git
- **服务器**：通过 GCP 控制台 **网页 SSH** 拉取/更新，systemd 守护运行

> A 股扫描器（`cmd/scanner`）的 HTTP/CLI 部署不在本文范围；参见 [项目规划](项目规划.md)、[技术方案](技术方案.md)。

---

## 1. 架构概览

```
本机 Windows                          GCP VM（CentOS）
┌─────────────────────┐              ┌──────────────────────────────┐
│ go build            │   git push   │ 网页 SSH                      │
│ crypto-scanner      │ ──────────►  │ git clone / git pull          │
│ (linux/amd64)       │              │ cp → /opt/find-assets/          │
└─────────────────────┘              │ systemd: crypto-scanner.service │
                                     │ OKX API ←→ 邮件 SMTP          │
                                     └──────────────────────────────┘
```

| 组件 | 说明 |
|------|------|
| 入口 | `crypto-scanner`（无后缀 Linux 二进制） |
| 运维通道 | GCP 控制台 → Compute Engine → **SSH**（浏览器终端） |
| 进程管理 | systemd |
| 密钥 | `/opt/find-assets/.env`（不进 Git） |
| 合约池缓存 | `/opt/find-assets/crypto/pools/` |

### 参考环境（示例）

| 项 | 值 |
|----|-----|
| 实例名 | `instance-20260706-114431` |
| Zone | `us-central1-f` |
| 机型 | `e2-micro`（GCP Always Free） |
| 系统 | CentOS Stream 10 |
| 安装路径 | `/opt/find-assets/` |

## 2. 本机：编译与发布

### 2.1 交叉编译

在 **PowerShell** 项目根目录执行：

```powershell
cd C:\Users\33002\Desktop\github\find-assets

$env:GOOS="linux"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go build -ldflags="-s -w" -o crypto-scanner ./cmd/crypto-scanner
```

说明：

- 必须 `GOOS=linux`，Windows 二进制无法在 CentOS 上运行
- 输出文件名 `crypto-scanner`（无 `.exe`），**不在** `.gitignore` 中，可提交 Git

### 2.2 提交到 Git

```powershell
git add crypto-scanner
git commit -m "build: update linux crypto-scanner binary"
git push origin main
```

仓库地址：`https://github.com/rechardlc/find-assets.git`

> **不要**提交 `.env` 或 SMTP 授权码；`.env` 已在 `.gitignore` 中。

## 3. 服务器：首次部署

以下命令均在 **GCP 网页 SSH** 中执行（非本机 Windows）。

### 3.1 登录

1. 打开 [GCP Console](https://console.cloud.google.com/) → **Compute Engine** → **VM 实例**
2. 点击实例右侧 **SSH**，进入浏览器终端
3. 确认用户名（通常为 Google 账号前缀，如 `lc523854439`）：

```bash
whoami
```

### 3.2 安装 Git

```bash
sudo dnf install -y git
```

### 3.3 创建目录并拉取代码

```bash
sudo mkdir -p /opt/find-assets
sudo chown $(whoami):$(whoami) /opt/find-assets

# 公开仓库
git clone https://github.com/rechardlc/find-assets.git /opt/find-assets/src
```

私有仓库使用 Personal Access Token：

```bash
git clone https://<TOKEN>@github.com/rechardlc/find-assets.git /opt/find-assets/src
```

### 3.4 安装二进制

```bash
cp /opt/find-assets/src/crypto-scanner /opt/find-assets/crypto-scanner
chmod +x /opt/find-assets/crypto-scanner
file /opt/find-assets/crypto-scanner
# 预期：ELF 64-bit LSB executable, x86-64
```

### 3.5 配置 SMTP 环境变量

```bash
tee /opt/find-assets/.env <<'EOF'
FIND_ASSETS_SMTP_PASS=你的QQ邮箱SMTP授权码
EOF
chmod 600 /opt/find-assets/.env
```

`tee` 会把内容同时打印到终端，属正常现象。授权码仅从 `.env` 读取，勿写入 systemd 或 Git。

### 3.6 单次扫描测试

```bash
cd /opt/find-assets
./crypto-scanner -schedule=false -source=okx
```

无报错、能输出扫描进度即可。测试完成后 `Ctrl+C` 退出。

### 3.7 配置 systemd 守护进程

使用**默认参数**，仅将数据源改为 OKX（GCP 美国区更稳定）：

```bash
sudo tee /etc/systemd/system/crypto-scanner.service <<'EOF'
[Unit]
Description=find-assets crypto scanner
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/find-assets
EnvironmentFile=/opt/find-assets/.env
ExecStart=/opt/find-assets/crypto-scanner -source=okx
Restart=always
RestartSec=30

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now crypto-scanner
sudo systemctl status crypto-scanner
```

#### 默认运行参数（未在 ExecStart 中写出时）

| 参数 | 默认值 |
|------|--------|
| `-schedule` | `true` |
| `-intervals` | `15m,1h,4h` |
| `-delay` | `20s` |
| `-pool` | `hot_alt` |
| `-top` | `200` |
| `-bars` | `300` |
| `-workers` | `10` |
| `-export` | `console` |
| `-mail` | `true` |
| 邮件 / SMTP | 见 `cmd/crypto-scanner/main.go` 默认值 |

## 4. 目录结构

```text
/opt/find-assets/
├── crypto-scanner          # 运行二进制（缓存根目录与此相同）
├── .env                    # SMTP 授权码（权限 600）
├── crypto/
│   └── pools/              # 合约池日缓存
│       └── hot_alt_YYYYMMDD_okx.json
├── output/                 # 仅 -export=json,md 时生成
└── src/                    # Git 仓库（含源码与二进制副本）
```

**注意**：合约池缓存写在**二进制所在目录**下的 `crypto/pools/`，与 `WorkingDirectory` 或 `src/` 无关。

## 5. 日常运维

所有命令在 **网页 SSH** 执行。

### 5.1 服务控制

```bash
# 查看状态
sudo systemctl status crypto-scanner

# 启动
sudo systemctl start crypto-scanner

# 停止
sudo systemctl stop crypto-scanner

# 重启（改配置或更新二进制后）
sudo systemctl restart crypto-scanner

# 取消开机自启
sudo systemctl disable crypto-scanner

# 恢复开机自启并启动
sudo systemctl enable --now crypto-scanner
```

### 5.2 查看日志

日志由 **systemd journal** 管理，不在 `/opt/find-assets/` 下。

```bash
# 实时跟踪
sudo journalctl -u crypto-scanner -f

# 最近 50 行
sudo journalctl -u crypto-scanner -n 50 --no-pager

# 今天
sudo journalctl -u crypto-scanner --since today --no-pager
```

正常日志示例：

```text
下一次扫描时间: 2026-07-06 15:20:20
  15m -> 2026-07-06 15:20:20
  1h  -> 2026-07-06 16:00:20
  4h  -> 2026-07-06 16:00:20
触发周期: 15m
使用今日合约池缓存: /opt/find-assets/crypto/pools/hot_alt_20260706_okx.json
```

#### 日志清理

journald 会按磁盘占用与时间**自动轮转**，一般无需手工维护。

```bash
# 查看日志占用
sudo journalctl --disk-usage

# 可选：手动清理 7 天前
sudo journalctl --vacuum-time=7d
```

### 5.3 查看缓存

```bash
ls -la /opt/find-assets/crypto/pools/
```

- 每天首次扫描拉取合约池并写入当日 JSON
- 同日后续扫描复用缓存
- 过期日期的池文件由程序自动删除

### 5.4 健康检查（一键）

```bash
echo "=== 服务 ===" && sudo systemctl is-active crypto-scanner
echo "=== 最近日志 ===" && sudo journalctl -u crypto-scanner -n 10 --no-pager
echo "=== 缓存 ===" && ls -la /opt/find-assets/crypto/pools/ 2>/dev/null || echo "暂无"
```

## 7. 修改配置

编辑 systemd 服务文件：

```bash
sudo vi /etc/systemd/system/crypto-scanner.service
```

常见调整示例：

```ini
# 仅 1h / 4h，减少 15m 扫描频率
ExecStart=/opt/find-assets/crypto-scanner -source=okx -intervals=1h,4h

# 关闭邮件
ExecStart=/opt/find-assets/crypto-scanner -source=okx -mail=false

# 结果落盘
ExecStart=/opt/find-assets/crypto-scanner -source=okx -export=json,md -out=/opt/find-assets/output
```

修改后：

```bash
sudo systemctl daemon-reload
sudo systemctl restart crypto-scanner
```

更新 SMTP 授权码（勿提交 Git）：

```bash
vi /opt/find-assets/.env
sudo systemctl restart crypto-scanner
```

## 8. GCP 免费层注意事项

| 项 | 建议 |
|----|------|
| 机型 | `e2-micro`，区域 `us-central1` / `us-west1` / `us-east1` |
| 网络层级 | VPC 使用 **Standard** 层级（出站免费额度更高） |
| 出站流量 | 仅用 OKX（`-source=okx`，默认值），请求带超时、全局限速（`-rate`）与退避重试 |
| 时区 | 保持 VM **UTC**，与交易所 K 线边界一致 |
| 防火墙 | crypto-scanner **无需开放入站端口** |
| 账单 | 建议设置 $1 预算告警 |

## 9. 安全

| 规则 | 说明 |
|------|------|
| `.env` 权限 | `chmod 600`，仅 root/运行用户可读 |
| 勿提交密钥 | `.env`、SMTP 授权码不进 Git、不进聊天记录 |
| 网页 SSH | 走 GCP IAP，优先于本机直连外网 22 端口 |
| 泄露后处理 | 立即在 QQ 邮箱重新生成 SMTP 授权码并更新 `.env` |

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| `file` 显示非 ELF | 本机编译未设 `GOOS=linux`，重新交叉编译 |
| `邮件通知已跳过：未配置 SMTP 授权码` | 检查 `/opt/find-assets/.env` 与 `EnvironmentFile` |
| 服务 `failed` | `sudo journalctl -u crypto-scanner -n 50 --no-pager` |
| `crypto/pools/` 为空 | 服务未跑完首轮，或尚未到扫描触发时间 |
| `git pull` 冲突 | `src/` 目录勿手改；仅通过本机 push 更新二进制 |
| 本机 `gcloud compute ssh` 失败 | 可仅用网页 SSH 运维，不影响服务运行 |
